## Hard-gate decision

The OpenHands-7B-Agent repository has no model card, no license metadata, and no
license or inheritance statement among the release files at the pinned revision.
The SWE-Gym repository itself being Apache-2.0 and its SFT dataset being MIT do
not license a separately released checkpoint. Therefore this project must not use
that checkpoint for formal training or reported V1 results.

V1 instead trains a LoRA Agentic-SFT adapter from the pinned Apache-2.0 Qwen2.5
Coder 7B base using the pinned MIT OpenHands trajectories, then uses only
SFT-unseen SWE-Gym tasks for executable-reward rollout and on-policy GRPO.

The conservative SFT-seen exclusion audit is generated by
`scripts/build_openhands7b_data_audit.py`. It maps public trajectory
`<pr_description>` text to SWE-Gym `problem_statement` using exact normalized
equality. Four ambiguous text matches exclude every candidate ID rather than
risking leakage.
